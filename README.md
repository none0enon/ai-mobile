# ai-mobile

AI 陪伴对话 App：像 SillyTavern 一样用角色卡、世界书、预设聊天，但她会**主动找你**，记得你说过的事，知道现在几点、下不下雨，陪你健身、做家务、吃饭、学习、睡觉、听歌、约会，也会打电话给你。

- 设计文档：[`docs/DESIGN.md`](docs/DESIGN.md)
- 当前进度：**M1 进行中**。
  - 已经是真的：导入 SillyTavern 角色卡（PNG / JSON，V1–V3，内嵌世界书自动拆出来绑定）、世界书、Chat Completion 预设；导入的东西和聊天存在本机（IndexedDB），刷新后还在；发消息时按 SillyTavern 的规则拼提示词（预设顺序、世界书扫描、宏、按深度插入、token 预算），"查看提示词"里看到的就是请求体。
  - 也是真的（在"我的 → API 设置"里填了 Key 之后）：多智能体调用（`packages/ai`）。主对话流式回复（自定义 / Claude / OpenAI 兼容 / Gemini / Vertex Agent / DeepSeek，移植自 math-reader），失败自动换备用 API；`[cg:]` 配图走生图提示词 + NovelAI；她的声音走 TTS（硅基流动 CosyVoice / MiniMax / 火山引擎 / Fish Audio / GPT-SoVITS）；向量化（测相似度、重算向量）；"写一段她的番外"。调用失败时显示完整报错（请求地址、状态码、响应头、服务商返回的原文）。设置存在本机，Key 单独保存；启用云端主动消息或连接云端每日节律后，仅相应功能使用的 API Key 会加密保存到自己的 Worker。
  - 语音消息：按住录音，松开后上传到配置的语音识别 API（硅基流动 SenseVoice / OpenAI 兼容），真实识别后发消息；录音存在本机，可播放和查看文字。上滑取消、离开聊天会释放麦克风，识别失败显示完整报错，不会代填演示台词。
  - 主动消息：Cloudflare Worker 每 5 分钟按各角色设置和你的时区独立排期、检测、生成，消息先存 D1，再通过 Web Push / Bark / ntfy / 自定义 webhook 通知。计划、勿扰时段、提示词中的当前时间和日期宏统一使用「我的 → 环境与作息」里选择的时区；修改并同步后，未发送的计划按新时区重新计算，已发送记录保留。App 关闭后仍运行；打开时按服务器游标补齐，固定消息 ID 防重复。角色并发执行，勿扰、最近聊天、规则冷却、未回复退避和每日 token 预算都在云端检查。入口「我的 → 云端与同步」，部署步骤见 [docs/CLOUDFLARE.md](docs/CLOUDFLARE.md)。
  - 语音通话：真的在打。说话检测（你说完了）→ 语音识别 → 主对话（"语音通话"选的预设，默认"通话 · 短句"）流式回复 → 按句合成语音、边合成边播放；你一开口她就停，聊天里只留下她说出口的部分。说的话都存进聊天，挂断时发通话记录卡片。也能"按住说话"或打字。
  - 哄睡：连麦（说话她就听得到：说话检测 → 语音识别 → 「陪伴 · 快速」按"哄睡"功能预设小声回你，你安静久了她低语一句）、她现编的睡前故事、定时到点的晚安，都用她的音色读出来；白噪音（雨声、炉火、海浪、风扇）在本机用 Web Audio 合成，不需要 API；音乐挑一个歌单放（网易云：助眠的几个、我们的歌单、搜一个或贴歌单链接）。
  - 人设可以分别打开**家务系统**和**健康系统**（"我的 → 我的人设"，存在本机）：
    - 家务：每天、每周要做的家务（刷牙早晚各一次、洗衣服周三周六、扫地一周两次……），每件写"没做时她会怎样"（嫌弃 / 不跟你约会 / 有点失落，想吃你做的 / 唠叨一句 / 自己写）；
    - 健康：身高体重、目标、能接受的健身方式、一周里每天能练多久、家里的食材、忌口、每顿能花多久做饭、有的厨具。
  - **共同的家**（地图上她的世界"一起做点什么"里，紧挨着"打电话"，一直都在；聊天 ＋ 里也有）：按家务清单列出今天要做的；点"开始"计时，做的时候能挑歌单放歌、和她打字聊或者连麦说话，做饭时能看今天计划里的菜谱；做完打勾她具体地夸你，"晚点"是拖一次、她按"没做时她会怎样"来反应。做完、拖延都发卡片进聊天（总结时记成习惯）。今天的家务和健康情况写进聊天、通话、一起做事、主动消息（本机和云端）的提示词：没刷牙没洗澡她会嫌弃，衣服没洗约她出门先拒绝，没做饭她有点失落、说要是能吃到你亲手做的番茄牛腩就好了——怎么反应写在预设里，能改。
  - **心跳**（地图上她的世界"一起做点什么"里，紧挨着"共同的家"，一直都在；聊天 ＋ 里也有）：只属于你们两个人的时间。背景是 NovelAI 画的整屏竖图（"生图 · 心跳"有氛围、第一视角、亲密三个预设，能换），打字聊或者连麦说话（各用各的预设）；连上 Intiface Central 后，她的话会变成玩具的震动、摆动、伸缩——新的"控制指令"预设按她每一句话写指令（键的写法沿用 SillyTavern 的 Intiface 插件），读到、念到那几个字时执行，不超过你设的强度上限，一键全部停下。
  - **一起游戏**有海龟汤和**真心话大冒险**两种，开始前在最上面切换，玩完一局还能接着玩、换着玩。真心话大冒险：选尺度（轻松 / 心动 / 大胆），转瓶子定谁先，之后轮流。轮到你时她按尺度、你们的关系和记忆出真心话或大冒险（每轮能换一次，不敢可以认罚，她会随口罚你一件小事）；轮到她时她自己选，你出题（可以让模型帮你想几个），她真诚地答、照着做。每一步按新的"一起游戏 · 真心话大冒险"预设（新的用途，场景里也能换）只发那一块；问答都存进聊天，不玩了发一张对局卡片。
  - **健康计划**（"我的 → 健康计划"，新的 AI 功能和新的"健康"预设）：按健康设置排这周（每天练什么、多久，三餐方向，要买的东西）和今天（热身、动作、拉伸，三顿饭的做法）；复杂的动作一步一步讲清楚、用大白话，不堆肌肉名称。
    - 接了 Google 地图时：外食只从附近真实的店里挑（种类、价位、评分、营业时间、能不能外带外送），饭卡上写去哪家、点什么、多远，能点开地图；要买的东西按附近超市和网店（美国：Amazon、Kroger、Walmart……）真能买到的商品和规格写，按在哪买分组，点一下在那家网站上搜。英文的店里的菜名、商品名写"中文（英文原名）"。
    - 做饭时间是 0 的那顿可以带提前做好的便当（隔夜燕麦也算）：要提前做的事（晚饭多做一份、睡前泡燕麦）发到"共同的家"今天的家务里提醒你，每件带没来得及做的备案；第二天看昨天做没做，没做就照备案排。
  - **健身**（以前的"一起运动"，照一起学习的样子、用立绘不生图）：按照计划（一个动作一个动作地练：按时间的组倒计时、组间休息倒计时、点开看怎么做）或者随便动动（从你的健身方式里挑、可以定时长）；记时长，心率、消耗可选，室外的加步数和距离。进阶记录先只做安卓：蓝牙心率带 / 手表心率广播、手机计步、GPS；别的手机练完手动填手表上的数。练完发运动卡片给她，她具体地评价。
  - 一起观影可以贴链接看：B 站 / YouTube 用官方嵌入播放器（参考 siios 的 co-watch），视频文件链接（.mp4 / .m3u8 …）用 App 自己的播放器。"贴链接"排在第一个。
  - 一起观影在手机、平板上开始就横屏全屏（放映厅），她的话从画面上飘过去；iPhone 的浏览器不能全屏时是一个没有内边距、铺满屏幕的框，屏幕竖着时里面转成横的。
  - 天气是真的：你那边用 Open-Meteo（免 Key，在美国用 NOAA 的模型，另取美国国家气象局的预警），住在国内的角色可以单独设城市、用和风天气（要 Key 和你自己的 API Host）。写进每轮的【当前环境】、聊天顶栏、地图、剧场的雨、约会推荐、配图的天气；取不到时写明原因，不编。
  - 一起听歌接真实的网易云音乐（同 SleepTogether：对接你自己部署的 Netease_url Worker，填同一个地址就行）：搜歌、贴歌单 / 专辑链接导入、真的播放、逐行歌词，她按歌词发弹幕。
  - 我的世界接真实的 Google 地图（填了 Key）：家的地址换成坐标、附近真实的咖啡店 / 餐厅 / 公园 / 健身房 / 图书馆、真地图；可以打开定位看你在不在家。健康计划也用它找附近能吃饭的地方和超市。
  - 聊天 ＋ → 拍照 / 相册：App 里开相机（会弹相机权限）或系统相机、系统相册多选；发出去先交给"识图"看，她照着看到的回你。
  - 记忆是真的（"总结 / 记忆""记忆整理""向量化"接通了 API 时）：每攒够 x 条（"我的 → 消息设置"，1–100）写一段梗概进时间线、按话题切故事片段（带氛围 / 特殊日子 / 重要标签）、抽记忆条目（注明来自第几行、发生时间）；记忆、片段、时间线、画像卡存在本机，刷新后还在。她每次回复完，在后台用这一轮的话按意思（向量）+ 按字面（单字和两字）搜好下一轮要带的记忆，发送时不用等；分路取（最相关、重要、今天的节日 / 纪念日、生病出差考试这类状态）、认得"上周 / 去年 / 第一次 / 上次"、上一轮带过的会回响两三轮。每天凌晨 4 点 Cloudflare 用"记忆整理"合并重复的记忆、合并时间线、把过期的事改成过去时、逐行修改画像卡（没连云端时打开 App 在本机补跑，记忆本里也能"立即整理"）。
  - 仍是演示或尚未接入：没填 Key 的文本智能体、完整多设备同步与素材备份，以及演示角色的初始内容、日记、今日活动。主动消息的上下文上传、云端收件箱和系统推送已经接通（云端写主动消息时还不带天气）。
  - 已定稿、还没做（设计见 [`docs/DESIGN.md`](docs/DESIGN.md)）：
    - **不写死任何预设**：内置的东西都和 `src/presets/` 一样放成文件，第一次打开时放进库里；角色导入时生成唯一 id（§5.5）。
    - **生图**：观影、看书、海龟汤、约会、吃饭的场景生图预设（现在跟随配图）；原创角色用定妆照 vibe（§10.3–§10.6）。
    - 主动消息按云端今日节律的作息来（每日节律生成与同步已接通）。

## 在线试用

部署在 GitHub Pages：https://none0enon.github.io/ai-mobile/ （`.github/workflows/pages.yml`：推到 main 时类型检查、构建并部署；PR 只做检查）。

- 第一次部署前，在仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。
- 可以装成 App（PWA）：iPhone 用 Safari 打开 → 分享 → 添加到主屏幕；安卓用 Chrome 打开 → 菜单 → 安装应用，或者在「我的 → 装成 App」里点安装。装好后全屏打开，断网也能进（AI 请求仍要联网）。
  - 卸载后装不回去：以前 manifest 的 `id` 写的是 `./`，浏览器按站点根目录解析成 `https://none0enon.github.io/`，可能和同一个 github.io 下的其他网页 App 撞在一起；现在是 `/ai-mobile/`。「我的 → 装成 App」里可以清理后台服务和缓存再刷新（聊天、角色、Key 不受影响），也写了各平台还装不上时怎么办。
- 在「我的 → API 设置」里按功能设置：点一个功能（主对话、番外、语音合成、生图……），选渠道、填地址和 Key、选模型（可以拉取列表），点「测试连接」。Key 只存在这台设备的浏览器里，请求从浏览器直接发给服务商。

## 本地运行

需要 Node 22.12+ 和 pnpm 10。

```bash
pnpm install
pnpm dev            # http://localhost:5173
pnpm typecheck      # vue-tsc + tsc
pnpm build          # 正式构建 → apps/web/dist（hash 路由，可放在任意静态目录）
pnpm build:preview  # 单文件预览页 → apps/web/artifact/index.html
```


## 可以在骨架里试的

- "我的 → 导入 ST 文件"：选一个 Chat Completion 预设、一张角色卡（PNG 或 JSON）。先显示识别结果，确认后导入；角色卡导入后直接去聊天，第一条是开场白。
  - 发一条消息，然后右上角 ⋯ → 查看提示词：能看到发出去的每一条消息、预设每一块发没发和为什么、世界书每一条触发没触发和为什么、请求体 JSON。
  - 预设的开关以 ST 实际生效的那套顺序（`prompt_order` 里的 100001）为准。那套里关掉的块（例如主提示、世界书位置）不会发送，和 SillyTavern 一样。

- 聊天里发"好累""想你""画一张""听歌""约会"：假模型会流式回复，并切换表情、发配图 / 歌曲卡、给选项、发起来电。没接生图 API 时，配图卡片上写"生图 API 还没接通"，不拿占位画冒充画好的图。
- 聊天 ＋ → 生成配图：选画什么（画一个场景 / 全身像 / 脸部特写 / 只画背景），可以写一句想画的画面（不写就按最近的聊天和她在哪画）。不经过聊天模型，直接用"配图"选的生图预设写 tags（生图提示词，默认跟随主对话的 API），再调"生图"的 API 出图；画好的图作为她发来的一张图放进聊天，点开能看提示词、种子、模型，能重新生成、保存图片。弹窗里写着这次用哪个预设、哪个模型、哪个生图 API，哪一步没接通就点"去设置"直接打开 API 设置里的那一项。
- 右上角切到剧场模式，点她的头、脸、肩膀（长按是摸头，连击会生气）。
- "地图"上面切换"苏晚的世界 / 江屿的世界 / 我的世界"：
  - 每个角色有自己的小世界，按作息出现在不同地方。点地点和她一起做事，默认是"连线"：你在你那儿、她在她那儿，各做各的、一起做。
  - 连线自习：她也在写她的论文，可以一起专注（共用一个计时器）或各自专注（上下分屏、各用各的计时器），见下面"陪伴学习"。饭搭子：拍你的饭给她看，她也在吃她那边的饭，还能碰个杯。场景右上角可以切到"坐在她旁边"。
  - 其他场景：健身、共同的家见下面；一起听歌见下面"一起听歌"。
  - "我的世界"是你的真实世界：家、附近可以带她去的地方，带她出门时她会"来你这边"；一起待过的地方记成"我们的足迹"。
    - 在"我的 → 地图、天气、音乐"里填了 Google 地图的 Key：家的地址用 Geocoding 换成坐标（地址变了才查），附近的地方来自 Places API (New) 附近搜索（每种最近的几个，缓存一天），画真地图（Maps JavaScript API）；点地点能"在 Google 地图里看"。没填 Key、Key 被拒时是示意图和演示地点，地图上写明原因。
    - Key 要开通 Maps JavaScript API、Geocoding API、Places API (New)，"网站限制"里加上 App 的地址。换 Key 后刷新一下页面。

- "我的 → 预设"：按用途分九类——对话、功能（一起吃饭、健身、共同的家、心跳……每件事一个，心跳的连麦另有"心跳 · 语音"）、主动消息、小剧场（番外）、总结、生图、节律、健康、控制指令（心跳里玩具的指令）。

  - 每个 AI 调用都按它用：聊天页里用角色的对话预设，在场景页里一起做某件事时用那件事的功能预设，主动消息用主动消息预设，番外、总结、配图的提示词（说明、规则、输出格式）也全在各自的预设里，代码里只填每次的输入。
  - 对话、功能、主动消息预设里新加了"家务和健康"（程序填你今天的情况）和"家务：你怎么反应""健康：你怎么反应"两块（只在你开了那套系统时发送）；以前放进本机的自带预设会自动补上，导入的 SillyTavern 预设没有时程序把自带的规则接在今天的情况后面。
  - 自带的预设是 `apps/web/src/presets/` 里的预设文件：第一次打开时像导入一样放进预设库，之后能改每一块的文字、加块删块、调顺序（手机上长按一块拖到想要的位置，按住左边的手柄可以直接拖；电脑上鼠标按住拖；拖到边缘会自动滚）、改参数，能复制（对话 / 功能 / 主动消息之间可以互相复制）、删除、导出成预设文件、恢复成文件里的样子。往这个文件夹里加一个 .json 就多一个自带预设。
  - "导入"能读 SillyTavern 的 Chat Completion 预设（选当对话、功能还是主动消息用），也能读预设文件。
  - 总结：攒够 x 条（消息设置里改，默认 30）还没整理的消息就在后台整理一段（"总结 / 记忆"接通了 API 时），聊天 ⋯ → 整理这段聊天 也能手动整理；梗概进时间线，故事片段和记忆进记忆本（存在本机），好感、心情、称呼跟着更新。提示词里的"过往摘要"是画像卡 + 时间线（越早越概括），"长期记忆"是关系 + 置顶和到期的 + 这一轮取到的记忆。
  - 记忆整理（"整理 · 记忆"预设，用途"记忆整理"，API 设置里和"总结 / 记忆"分开配置）：合并重复的记忆、时间线同层满 4 段合成一段、过期的待跟进改时态、逐行修改画像卡。连了云端每天凌晨 4 点自动跑；你在手机上改过的那一处不会被覆盖。总结和整理都不设每日上限。
- 预设 → 正则（SillyTavern 正则脚本，随预设保存）：

- 我的 → 消息设置：
  - 发送给 AI：限制条数后仅发送最近 N 条聊天记录（0–100，0 表示不发送），之后仍受预设上下文长度限制。聊天、场景、通话、主动消息（本机和云端）均适用。
  - 显示：限制条数后聊天仅显示最近 N 条（1–100），顶部可展开更早的消息。
  - 总结：每多少条整理一次（1–100）；自动隐藏已总结的消息（顶部可展开）；已总结的消息不发送给 AI（提示词里用时间线和取到的记忆代替，聊天、场景、通话、主动消息本机和云端都适用）。
  - HTML 渲染（默认开启）：消息中的 HTML 按白名单渲染（`<details>`、`<b>`、表格、图片等；脚本、事件属性、`<style>`、`<iframe>` 移除，未知标签保留文本）。代码块中的完整 HTML 页面（播放器、状态栏等前端卡）在沙盒 iframe 中运行，无法访问应用数据；仅渲染最近 N 条（0–50，默认 5），其余折叠为代码。支持酒馆助手的 `getCurrentMessageId`、`getLastMessageId`、`eventOn`、`eventEmit`。
- "我的 → API 设置"：接真实模型，按功能分（不按渠道分）。
  - 文本功能（主对话、番外、总结、记忆整理、生图提示词、健康计划、控制指令、主动消息、识图）的渠道：自定义（任意地址，请求格式可选 Gemini / OpenAI / Claude，默认 Gemini，同 math-reader 的自定义渠道）、Claude、OpenAI 兼容、Gemini、Vertex Agent、DeepSeek。番外这些默认跟随主对话，也可以单独设置。
  - 其他功能的渠道：自定义（OpenAI 格式，任意地址）和能做这件事的几家——向量化：硅基流动、Gemini；语音合成：硅基流动、MiniMax、火山引擎、Fish Audio、GPT-SoVITS；生图：NovelAI（含公益站）、硅基流动；语音识别：硅基流动 / 自定义 OpenAI 兼容接口（`/audio/transcriptions`）。硅基流动拉取语音识别模型时按 `speech-to-text` 筛选，连接测试上传本地生成的静音 WAV，不开启麦克风。
  - 每个功能填地址、Key、模型（"拉取模型列表"或手动填），"测试连接"；可以再设一个失败时改用的备用 API；也能照搬别的功能的设置。本机、局域网地址和自建 GPT-SoVITS 可以不填 Key。
  - 测试失败、拉取失败、聊天回复失败都显示完整报错：请求地址（Key 已隐去）、状态码、响应头、服务商返回的原文、底层错误；备用 API 也失败时两边都列出来，可以复制。卡片上写着"已接通"还是"演示模型"以及原因，最近一次调用失败也在卡片上。
  - 会思考的模型（Gemini 2.5 起、Claude 5、o 系列、DeepSeek……）把思考也算在回复上限里：发请求时在预设的"最长回复"之外留出思考的余量，通话、戳一戳、哄睡这些给短句的功能不会再被思考吃光（以前回复是空的，或者故事只有标题）。通话、哄睡、看片时随口一句在 Gemini / DeepSeek / Claude 原生接口上会尽量少思考，回得更快；你在 API 设置里自己设了推理强度时照你的。
  - 语音合成里的"CosyVoice 情绪指令"默认关：有的服务会把"你能用……的语气说吗？"这句指令原样念出来。确定你的服务认这个写法（硅基流动的系统音色）再打开。
  - 以前按连接分的设置（连接 + 主要 / 次要 / 备用 API）第一次打开时自动转过来，Key 跟着搬。番外、总结等后台功能可以设每日 token 上限。
  - 向量化可以测相似度、用新模型重算向量。
  - 主对话填好后，聊天就是真的模型在回；她回复里的 `[cg:…]` 会真的出图（存在本机素材库）；回复失败时气泡下写着原因，可以重新生成。`[cg:画面描述]` 的写法和什么时候用写在程序填充的"当前场景规则 + 可用标签"块里，所以导入的 SillyTavern 预设也会用。
