# ai-mobile

AI 陪伴对话 App：像 SillyTavern 一样用角色卡、世界书、预设聊天，但她会**主动找你**，记得你说过的事，知道现在几点、下不下雨，陪你运动、吃饭、学习、睡觉、听歌、约会，也会打电话给你。

- 设计文档：[`docs/DESIGN.md`](docs/DESIGN.md)
- 当前进度：**M1 进行中**。
  - 已经是真的：导入 SillyTavern 角色卡（PNG / JSON，V1–V3，内嵌世界书自动拆出来绑定）、世界书、Chat Completion 预设；导入的东西和聊天存在本机（IndexedDB），刷新后还在；发消息时按 SillyTavern 的规则拼提示词（预设顺序、世界书扫描、宏、按深度插入、token 预算），"查看提示词"里看到的就是请求体。
  - 也是真的（在"我的 → API 设置"里填了 Key 之后）：多智能体调用（`packages/ai`）。主对话流式回复（自定义 / Claude / OpenAI 兼容 / Gemini / Vertex Agent / DeepSeek，移植自 math-reader），失败自动换备用 API；`[cg:]` 配图走生图提示词 + NovelAI；她的声音走 TTS（硅基流动 CosyVoice / MiniMax / 火山引擎 / Fish Audio / GPT-SoVITS）；向量化（测相似度、重算向量）；"写一段她的番外"。调用失败时显示完整报错（请求地址、状态码、响应头、服务商返回的原文）。设置存在本机，Key 单独保存；启用云端主动消息后，仅该功能使用的 API Key 会加密保存到自己的 Worker。
  - 语音消息：按住录音，松开后上传到配置的语音识别 API（硅基流动 SenseVoice / OpenAI 兼容），真实识别后发消息；录音存在本机，可播放和查看文字。上滑取消、离开聊天会释放麦克风，识别失败显示完整报错，不会代填演示台词。
  - 主动消息：Cloudflare Worker 每 5 分钟按各角色设置和你的时区独立排期、检测、生成，消息先存 D1，再通过 Web Push / Bark / ntfy / 自定义 webhook 通知。App 关闭后仍运行；打开时按服务器游标补齐，固定消息 ID 防重复。角色并发执行，勿扰、最近聊天、规则冷却、未回复退避和每日 token 预算都在云端检查。入口「我的 → 云端与同步」，部署步骤见 [docs/CLOUDFLARE.md](docs/CLOUDFLARE.md)。
  - 仍是演示或尚未接入：没填 Key 的文本智能体、真实语音通话、完整多设备同步与素材备份，以及演示角色的初始内容、记忆、天气、今日活动。主动消息的上下文上传、云端收件箱和系统推送已经接通。
  - 已定稿、还没做（设计见 [`docs/DESIGN.md`](docs/DESIGN.md)）：
    - **不写死任何预设**：内置的东西都和 `src/presets/` 一样放成文件，第一次打开时放进库里；角色导入时生成唯一 id（§5.5）。
    - **生图**：观影、看书、海龟汤、约会、吃饭的场景生图预设（现在跟随配图）；原创角色用定妆照 vibe（§10.3–§10.6）。
    - **节律**：凌晨由 Worker 排今天、主动消息按今天的作息来（现在是当天第一次打开 App 时在本机排）。

```
  src/services/      服务接口 + 假实现（假的流式模型会吐 [expr:] 等控制标签）

  src/st/            SillyTavern 兼容：PNG 文本块、角色卡 / 世界书 / 预设的导入导出、宏、世界书扫描、提示词拼装

  src/llm/           文本对话：OpenAI 兼容 / DeepSeek / Claude / Gemini / Vertex Agent（流式、思考内容、流式失败改普通请求、按报错调整参数）
  src/tts/ image/ embedding/   语音合成（含火山引擎声音复刻）、生图（NovelAI、OpenAI 兼容）、向量化
  src/channels.ts    渠道表：每个功能能选哪些渠道、默认地址和常用模型

```

`apps/hub` 已提供 Cloudflare Worker + D1 主动消息中枢；R2 素材备份和 `apps/android`（WebView 壳）后续实现。

## 在线试用

部署在 GitHub Pages：https://none0enon.github.io/ai-mobile/ （`.github/workflows/pages.yml`：推到 main 时类型检查、构建并部署；PR 只做检查）。

- 第一次部署前，在仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。
- 可以装成 App（PWA）：iPhone 用 Safari 打开 → 分享 → 添加到主屏幕；安卓用 Chrome 打开 → 菜单 → 安装应用，或者在「我的 → 装成 App」里点安装。装好后全屏打开，断网也能进（AI 请求仍要联网）。
  - 卸载后装不回去：以前 manifest 的 `id` 写的是 `./`，浏览器按站点根目录解析成 `https://none0enon.github.io/`，可能和同一个 github.io 下的其他网页 App 撞在一起；现在是 `/ai-mobile/`。「我的 → 装成 App」里可以清理后台服务和缓存再刷新（聊天、角色、Key 不受影响），也写了各平台还装不上时怎么办。
- 在「我的 → API 设置」里按功能设置：点一个功能（主对话、番外、语音合成、生图……），选渠道、填地址和 Key、选模型（可以拉取列表），点「测试连接」。Key 只存在这台设备的浏览器里，请求从浏览器直接发给服务商。

## 本地运行

需要 Node 22.12+ 和 pnpm 10。

```bash
pnpm install
pnpm dev            # http://localhost:5173
pnpm typecheck      # vue-tsc + tsc
pnpm test           # 云端主动消息：workerd + D1、并发/幂等/重试/时区、Service Worker
pnpm build          # 正式构建 → apps/web/dist（hash 路由，可放在任意静态目录）
pnpm build:preview  # 单文件预览页 → apps/web/artifact/index.html
```


## 可以在骨架里试的

- "我的 → 导入 ST 文件"：选一个 Chat Completion 预设、一张角色卡（PNG 或 JSON）。先显示识别结果，确认后导入；角色卡导入后直接去聊天，第一条是开场白。
  - 发一条消息，然后右上角 ⋯ → 查看提示词：能看到发出去的每一条消息、预设每一块发没发和为什么、世界书每一条触发没触发和为什么、请求体 JSON。
  - 预设的开关以 ST 实际生效的那套顺序（`prompt_order` 里的 100001）为准。那套里关掉的块（例如主提示、世界书位置）不会发送，和 SillyTavern 一样。

- 聊天里发"好累""想你""画一张""听歌""约会"：假模型会流式回复，并切换表情、发配图 / 歌曲卡、给选项、发起来电。没接生图 API 时，配图卡片上写"生图 API 还没接通"，不拿占位画冒充画好的图。
- 聊天 ＋ → 生成配图：选画什么（画一个场景 / 全身像 / 脸部特写 / 只画背景），可以写一句想画的画面（不写就按最近的聊天和她在哪画）。不经过聊天模型，直接用"配图"选的生图预设写 tags（生图提示词，默认跟随主对话的 API），再调"生图"的 API 出图；画好的图作为她发来的一张图放进聊天，点开能看提示词、种子、模型，能重新生成、保存图片。弹窗里写着这次用哪个预设、哪个模型、哪个生图 API，哪一步没接通就点"去设置"直接打开 API 设置里的那一项。
- 右上角切到剧场模式，点她的头、脸、肩膀（长按是摸头，连击会生气）。
- "地图"上面切换"苏晚的世界 / 江屿的世界 / 我的世界"：
  - 每个角色有自己的小世界，按作息出现在不同地方。点地点和她一起做事，默认是"连线"：你在你那儿、她在她那儿，各做各的、一起做。
  - 连线自习：共用番茄钟，她也在写她的论文。饭搭子：拍你的饭给她看，她也在吃她那边的饭，还能碰个杯。场景右上角可以切到"坐在她旁边"。
  - 其他场景：运动是加速演示，听歌的歌词会滚动、她会发弹幕。
  - "我的世界"是你的真实世界（接 Google 地图前是示意图）：家、附近可以带她去的地方，带她出门时她会"来你这边"；一起待过的地方记成"我们的足迹"。
  - 家的地址在"我的 → 环境与作息"里填，只存在本机。
- 消息按人分：一个角色只有一条聊天。去过的场景在聊天里是一段"来到… / 离开…"；在场景里点她的话可以去聊天接着聊。
- 一起看书也能读带公式的专业书（教材、讲义、论文，参考 math-reader 和 SleepTogether 的看书）：
  - PDF 有两种看法：原版页面（pdf.js 照原样画，可以放大）和重排成文字，书页上方切换。
  - 扫描页、文字层读出来是乱码的页、有公式的页（文字层里的公式是乱的）先原样显示；"识图"接通时，提前把现在这页和后面两页读成 Markdown + LaTeX，读好就换成文字。拍下的书页也这样读。
  - 公式用 KaTeX 显示（$…$ 行内、$$…$$ 单独一行，用到时才加载，装成 App 后断网也能显示）：正文、她的页边批注、她说的话、聊天气泡里都是。在正文里选中一段公式写批注，划的就是公式原文。
  - 她读专业书时写的批注是"这一步用了哪条定理、这个记号什么意思"，公式也用 LaTeX；习题不先说答案。读给你听时公式念成中文（"从 a 到 b 的积分""e 的负 i 西塔次方"）。
  - 识图读法和"专业书"怎么批注都在"一起看书"功能预设里，能改；以前放进本机的这份预设，没改过的识图说明会自动换成新的，"专业书"一块会补上。
- "我的 → 预设"：按用途分七类——对话、功能（一起吃饭、一起运动……每件事一个）、主动消息、小剧场（番外）、总结、生图、节律。
  - 每一类上面是"用在哪"：对话预设每个角色自己选；一起做事的每件事、主动消息、番外、总结、配图、节律各选一个这一类的预设（一起做事和主动消息也能"跟随对话预设"）。
  - 生图这一类除了"配图"，一起做事的每件事也各有一项（一起做事时画的图），可以选别的生图预设或"跟随配图"。自带的"生图 · 陪伴学习"按入座、偷拍、奖励三个时刻各发一块；块里能用 `{{char_appearance}}`（她的长相）、`{{char_outfit}}`（节律里她今天这个场景穿的那套）、`{{user_appearance}}`。
  - 每个 AI 调用都按它用：平时聊天用角色的对话预设，一起做某件事时用那件事的功能预设，主动消息用主动消息预设，番外、总结、配图的提示词（说明、规则、输出格式）也全在各自的预设里，代码里只填每次的输入。
  - 自带的预设是 `apps/web/src/presets/` 里的预设文件：第一次打开时像导入一样放进预设库，之后能改每一块的文字、加块删块、调顺序（手机上长按一块拖到想要的位置，按住左边的手柄可以直接拖；电脑上鼠标按住拖；拖到边缘会自动滚）、改参数，能复制（对话 / 功能 / 主动消息之间可以互相复制）、删除、导出成预设文件、恢复成文件里的样子。往这个文件夹里加一个 .json 就多一个自带预设。
  - "导入"能读 SillyTavern 的 Chat Completion 预设（选当对话、功能还是主动消息用），也能读预设文件。
  - 总结：攒够 30 条还没整理的消息就在后台整理一段（"总结 / 记忆"接通了 API 时），聊天 ⋯ → 整理这段聊天 也能手动整理；摘要进提示词里的"过往摘要"，记下的事进记忆本（记忆还没存进本机），好感、心情、称呼跟着更新。
- "我的 → API 设置"：接真实模型，按功能分（不按渠道分）。
  - 文本功能（主对话、番外、总结、生图提示词、主动消息、识图）的渠道：自定义（任意地址，请求格式可选 Gemini / OpenAI / Claude，默认 Gemini，同 math-reader 的自定义渠道）、Claude、OpenAI 兼容、Gemini、Vertex Agent、DeepSeek。番外这些默认跟随主对话，也可以单独设置。
  - 其他功能的渠道：自定义（OpenAI 格式，任意地址）和能做这件事的几家——向量化：硅基流动、Gemini；语音合成：硅基流动、MiniMax、火山引擎、Fish Audio、GPT-SoVITS；生图：NovelAI（含公益站）、硅基流动；语音识别：硅基流动 / 自定义 OpenAI 兼容接口（`/audio/transcriptions`）。硅基流动拉取语音识别模型时按 `speech-to-text` 筛选，连接测试上传本地生成的静音 WAV，不开启麦克风。
  - 每个功能填地址、Key、模型（"拉取模型列表"或手动填），"测试连接"；可以再设一个失败时改用的备用 API；也能照搬别的功能的设置。本机、局域网地址和自建 GPT-SoVITS 可以不填 Key。
  - 测试失败、拉取失败、聊天回复失败都显示完整报错：请求地址（Key 已隐去）、状态码、响应头、服务商返回的原文、底层错误；备用 API 也失败时两边都列出来，可以复制。卡片上写着"已接通"还是"演示模型"以及原因，最近一次调用失败也在卡片上。
  - 以前按连接分的设置（连接 + 主要 / 次要 / 备用 API）第一次打开时自动转过来，Key 跟着搬。番外、总结等后台功能可以设每日 token 上限。
  - 向量化可以测相似度、用新模型重算向量。
  - 主对话填好后，聊天就是真的模型在回；她回复里的 `[cg:…]` 会真的出图（存在本机素材库）；回复失败时气泡下写着原因，可以重新生成。`[cg:画面描述]` 的写法和什么时候用写在程序填充的"当前场景规则 + 可用标签"块里，所以导入的 SillyTavern 预设也会用。
- 陪伴学习的画面是生图画的（"生图"接通时；没接通时照常是立绘，面板上写明为什么、点"去设置"）：
  - 进来画一张她坐下的样子（入座）；今天在同一个地方、穿同一身画过的，直接用图库里的那张，不重画；
  - 每个番茄中间自动偷拍一张她专心、卡住或者打瞌睡的样子；点"看她一眼"马上画一张，有时她会发现你在看；
  - 学完画一张（奖励），和这次画的几张一起放进聊天里的学习卡片，点开看大图；
  - 衣服是节律里她今天那套（同一天的图衣服一致）；长相按角色设定（同人是角色 tag + 作品 tag）；
  - 一次只画一张，你点的排在自动画的前面；右上角的图片按钮能关掉自动画；NovelAI 只在不花点的设置下自动画（步数 ≤ 28、不用 V5）。
- "我的 → 节律"：上面一排头像选看谁的。
  - 导入的角色先"建世界"：「节律」从角色卡和世界书里找出她住哪、在哪读书或工作、常去哪、身边有谁，写出作息模板、三餐习惯和衣柜；先给你看，确认后地图上就有她的小世界，她按作息出现在不同的地方。
  - 怎么排：固定（一直按模板）或每天变化（作息、三餐、穿着分别勾；穿着从衣柜里挑着搭或每天新编）。每天变化的在当天第一次打开 App 时交给「节律」排（凌晨 4 点换一天），排出来的会检查：盖满一整天、不重叠、地点都在她的世界里、标了"固定"的事不挪，不合格的部分用模板补。
  - 今天的时间线（标出"现在"）、三餐、穿着（中文名 + NovelAI tags，能改）、手头的事；"重新排今天""存成模板"；模板（作息、三餐、衣柜、手头的事）展开就能改；最近 7 天。
  - 用在：她此刻在哪、在做什么；陪伴学习里她的小目标；一起吃饭她吃什么；一起做事时画的图穿哪套；聊天提示词的【当前环境】里写她今天穿什么。
  - API 设置里的「节律」默认跟随「陪伴 · 快速」；提示词在预设页"节律"一类（自带"节律 · 建世界和排今天"）。
- 角色设定 → 生图：出自已有作品的角色打开"同人角色"，填角色 tag（例如 `hatsune miku`、`rem (re:zero)`）和作品 tag，生图时直接写它们，不用一条条描述长相；原创角色关着，按外观 tags 画。"试画一张"真的出图（白底全身像），看看 NovelAI 认不认得。角色卡列表上同人角色标着"同人"；导入角色后也有入口。
- 横着放不下的一排（预设分类、看谁的世界 / 回忆、主动消息和试一试的人物、配色、记忆筛选、服装、白噪音）：手机上手指横划；电脑上鼠标滚轮上下滚就会左右走，也能按住拖，两头还有没露出来的就显示箭头，点一下滚过去；选中的那个自动滚到看得见的地方。

- "我的 → 主动消息"：上面一排头像切换角色，每个角色单独开关、选性格、选在哪些时候来找你，看今天的计划。

  - 上传你和她们的头像。
